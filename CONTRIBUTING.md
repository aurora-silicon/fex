# Contributing

This is Aurora Silicon's fork of [FEX-Emu/FEX](https://github.com/FEX-Emu/FEX).
Contributions here, including code written with AI assistants, follow
Aurora Silicon's policy in [.github/aurora/AGENTS.md](.github/aurora/AGENTS.md).

Changes meant for upstream FEX follow upstream's rules instead, which
accept no AI/ML/LLM code contributions.
